# 🤖 Aexo

> **Your AI Sidekick. Always On. Always Smart.**

Aexo is a powerful, multimodal conversational AI assistant designed to orchestrate complex prompt context windows and streamline daily tasks. Built with a sleek, user-friendly interface, Aexo acts as a comprehensive productivity hub offering everything from real-time voice interactions to multimodal file processing. 

---

## ✨ Key Features

Based on the application screens, here is what Aexo brings to the table:

*   **Seamless Authentication:** Secure user login and registration system with support for standard Email/Password credentials and Google OAuth (`Continue with Google`).
*   **Multimodal Capabilities:** 
    *   **Text & Voice:** Engage in natural conversations via text or use the "Live with Aexo" feature for real-time voice interactions.
    *   **File Processing:** Upload and process both Images and PDFs directly within the chat interface for deeper contextual analysis.
*   **Dedicated Workspaces:**
    *   **Chat Assistant:** The core conversational engine for general queries.
    *   **Idea Lab & Idea Generator:** Brainstorming modules for startup ideas, creative writing, and complex topic breakdowns.
    *   **Image Studio:** Dedicated space for generating creative and surreal AI imagery.
    *   **Deep Search & Quick Tasks:** Specialized tools for rapid information retrieval and task execution.
*   **Persistent Chat History:** Easily search, access, and resume previous conversations from a dedicated history sidebar.
